invoice-packet-checker

Check an invoice packet before a factoring submission: which required documents are missing, which classified files are empty, and whether load numbers disagree.

Format: each file starts with a line @file NAME, followed by its text content, until the next @file line. A file with no content lines counts as an empty file. Choosing files above fills this in for you. Non-text files (for example PDFs) can be listed with an @file line and no content: they still count for the missing-document check, like in the CLI.

Press Run to see the report.
